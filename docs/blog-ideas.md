# Blog Ideas — DEEP 작성 후보 백로그

나중에 작성할 블로그 주제를 캡처해두는 파일. 작성이 끝난 주제는 이 파일에서 제거한다.

DEEP 모토 — **"No silver bullet + 트레이드오프 우선"** — 에 맞춰, 단순 사용법/튜토리얼은 거절하거나 트레이드오프 각도로 재구성한다.

작성 시작 시 `blog-writer` 스킬을 통해 학습 Q&A → 노트 정리 → MDX 생성 3단계로 진입한다.

## 메모

- 학습 흐름상 **인덱스 → 빅오 → 카디널리티 → EXPLAIN** 순서로 시리즈화 가능.
- 주제 간 상호 참조가 많으므로, 먼저 쓰는 글에서 다른 주제를 키워드로 예약해두면 자동 링크 파이프라인이 연결을 만들어 준다.
